# Instalador do Treinador TCG

**[Baixar o instalador (Instalar-Treinador-TCG.exe)](https://github.com/treinador-tcg/treinador-tcg/raw/instalador/Instalar-Treinador-TCG.exe)**

1. Abra o arquivo baixado. Se o Windows avisar "O Windows protegeu o
   computador", clique em **Mais informações → Executar assim mesmo**.
2. Clique em **Instalar** e, no fim, em **Concluir**. Não pede senha de
   administrador e leva de 1 a 3 minutos.
3. O Treinador abre numa janela própria. Digite o seu código de licença
   (TTCG-XXXX-XXXX-XXXX) e clique em **Ativar**.

Depois, abra pelo atalho **Treinador TCG** (Área de Trabalho ou menu
Iniciar). Ele se atualiza sozinho toda vez que abre.

Precisa de Windows 10 ou 11 (64 bits) e internet.
